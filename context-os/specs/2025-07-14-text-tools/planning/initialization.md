# Text Tools - Raw Idea

**Date:** 2025-07-14
**Source:** User request (voice-to-text)

## Raw Input

Create a very lightweight HTML web page tool that can be spawned. Purpose: provide text manipulation utilities.

### Requested Features
- Remove extra spaces between words
- Remove extra line breaks
- Targeted find and replace
- Before/after dual-pane view to see changes
- Single page tool with two panes showing the design

### Design Requirements
- Dark UI theme
- Elegant, modern aesthetic
- No emojis anywhere
- Mono-color icons only (no multi-color)
- Lightweight / single HTML file
